# 0009. Сокращённое расписание F5 для CUDA

Предложено для ветки `perf/fast-tts`, 22.11.2026. Дополняет [ADR 0002](0002-onnx-runtime.md).

## Контекст

На RTX 3060 основную задержку создают вызовы Transformer. В исходном экспорте FP16 уже используется для шума и условий. В граф зашиты две таблицы. Одна задаёт представление времени для каждого шага, вторая задаёт величину шага Эйлера. После нескольких первых итераций исходного графа сигнал ещё зашумлён.

## Решение

В ускоренных профилях компаньон строит производный Transformer из известного экспорта. Для каждого интервала он берёт представление времени в левой границе и суммирует исходные приращения до следующей границы. Последний интервал доходит до исходного конца. Исходные веса, CFG и модель длительности сохраняются. Выбор границ проверяется на одном корпусе с разными голосами. Для малых чисел шагов за основу взяты сетки EPSS. [Реализация F5-TTS](https://github.com/SWivid/F5-TTS/blob/main/src/f5_tts/model/utils.py)

Программа проверяет SHA-256 исходного Transformer. Пакет `onnx` нужен при первом построении варианта. Готовый файл публикуется атомарно в `data/tmp/f5-schedules`. У каждого расписания свой файл. При первом прогреве CUDA Decode сравнивается с CPU Decode на одинаковых входных тензорах. Preprocess, Transformer и Decode передают друг другу OrtValue на GPU. Число шагов и условные тензоры берутся из расписания известной FP16-модели. Ускоренные CUDA-сессии используют вариант свёртки NC1D и эвристический выбор алгоритма cuDNN. [Параметры CUDA EP](https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html)

TensorRT включается явным путём к библиотекам NVIDIA и заменяет только Transformer. Профиль динамических размеров охватывает диапазон длительностей экспорта. Компилированный движок кэшируется с привязкой к GPU, драйверу, библиотекам, версии ORT, расписанию и настройкам сборщика. При ошибке TensorRT компаньон повторяет строку через CUDA с тем же расписанием. [Параметры TensorRT EP](https://onnxruntime.ai/docs/execution-providers/TensorRT-ExecutionProvider.html)

## Альтернативы

Отдельные полные наборы моделей увеличили бы объём загрузки и потребовали бы отдельной публикации для каждого числа шагов. Для неизученных экспортов, DirectML и профиля `quality` используется исходное расписание. Ошибка ускоренного инференса переключает текущую строку на обычный F5. Ошибку загрузки обычного F5 обрабатывает существующий механизм выбора SAPI.

## Последствия

Первый запуск ускоренного профиля требует дополнительной оперативной памяти и места на диске для производного графа. На следующих запусках файл берётся из кэша. При смене исходной модели ускорение потребуется проверить заново. Замеры и условия воспроизведения приведены в [отчёте по RTX 3060](../tts-benchmark.md).
